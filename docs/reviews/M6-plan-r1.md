# Review M6-Plan r1 (speccritic)

VERDICT: BLOCKER

1. **Fremde Abgaben lesbar** (§2.3 „Rechte“, `noteLevel` für `role=submission`): „sonst `requireAssignment(read)` → READ“. Laut §9.7 hat S (Schüler mit eigener Abgabe) `read` auf die Aufgabe → S2 bekäme READ auf die Kopie-Notiz von S1 (und damit Anhänge, Snapshots, `revisions.php`, Export). Verstößt gegen §9.4/Krit. 4. Fehlt: für fremde Abgaben eine reine Lehrkraft-Aktion (L aktiv, O verwaist/eingefroren), gleiche Regel für `requireSubmission`. Zusätzlich Widerspruch zur Invariante `filterReadable ≡ noteLevel ≥ READ` (SPEC §3, M6a Done 8): Lehrkraft hat per `noteLevel` READ auf Abgaben, `filterReadable` blendet sie aus. Invariante in SPEC §3 und im Plan neu fassen (z. B. „≡ für `role=note`; Abgaben/Vorlagen nur über Direktzugriff“) und FilterReadableTest entsprechend.
2. **Material: Schreibwege unvollständig** (§2.1, Done M6a 1–5). Im Code (`ee18183a`) ohne Abdeckung im Plan:
   - `NoteService::clearFavorites` (nur Workspace-`write`, setzt `favorite` aller Notizen und Ordner des Workspace inkl. Material).
   - `NoteService::reorder` Scope `speed_dial` (Geschwister workspaceweit), `dashboard`/`kanban`/`sidebar` (Geschwister im Ordner) – schreibt Reihenfolgespalten an Notizen, geprüft werden nur Notiz und Ziel; analog `FolderService::reorder`.
   - `NoteService::moveToFolder` mit `folder`-Name: vorhandener Ordner wird per `findInWorkspace` gefunden und **ohne** `requireFolder(…,'write')` als Ziel genommen → S verschiebt eigene Notiz per Name in einen Material-Ordner.
   Fehlt: Liste aller Sammel-/Nebenschreiber in `writeExcludedFolderIds` bzw. Ziel-Prüfung, Done-Fälle dafür, Kompat-Routen (`api_save_excalidraw.php` u. a.) explizit in M6a-Done statt erst M6h. `MaterialIsolationTest` gehört nach M6a, da M6a–c vorab an die Demo gehen.
3. **Quote O1 nicht umsetzbar beschrieben** (§2.3 „Anlegen“, Done M6d 7): `QuotaService::quotaFor` arbeitet je Workspace-Besitzer. Vorlagen haben `workspace_id NULL`, Kopien liegen in `kind=assignments` mit `owner_type=user` (Schüler) → heute Schüler-Quote und Sperre der Schüler-Workspace-Zeilen; abgelöste Kopien haben keinen Workspace. Fehlt: Zuordnung Vorlage/Kopie/abgelöste Kopie → Team-Quote, Ausschluss aus der Benutzer-Quote des Schülers (`AttachmentService::usage`), welche Zeile(n) parallel hochladende Schüler eines Teams serialisieren (Team-Workspace-Zeilen allein tun es nicht), Verhalten von `distribute`/`reconcile` bei Quote-Überschreitung (Abbruch je Schüler? `pending`? Fehlercode), damit keine Teil-Austeilung ohne Meldung entsteht.

Hinweise
- H1 Rennen Austeilen (§2.4): Je-Schüler-Transaktion muss Aufgabenzeile sperren und `distributed` + Team `active` erneut lesen, sonst legt `distribute`/`reconcile` nach parallelem DELETE/`close`/Purge Abgaben zu einer gelöschten Aufgabe an. Sperr-Reihenfolge um „Abgabe“ ergänzen (`submit`: Notiz → Abgabe) und gegen vorhandene Quote-Sperre in `NoteService::update` (Workspace-Zeilen nach Notizsperre?) prüfen und dokumentieren.
- H2 Kennzeichen vs. Ordner-Verschieben: Verschiebepfade müssen `materialFolderIds` unter der Workspace-Sperre neu berechnen (Cache leeren), sonst wirkt die Sperre aus R2 nicht.
- H3 O3 (synchron) tragfähig und SPEC §8-nah; Bedingung: Lösen der Kopien und `owner_type=deleted` in einer Transaktion; `UserDataService::purgeWorkspaces`/`WorkspaceDeletion` überspringen `role≠note` defensiv. `transferOwnership` im synchronen Listener darf bei Circles-Fehler nicht werfen (→ NULL), sonst bricht die Kontolöschung wiederholt ab.
- H4 SPEC §9.1.6 nennt `ZipResponse`, Plan `ExportArchive`: Zeile in §4-Tabelle ergänzen. ADR 0008 a („Arbeit in QueuedJob“) im Nachtrag ausdrücklich ändern.
- H5 `left_team_at` zurücksetzen bei Wiedereintritt unabhängig von der Frist (reconcile prüft sonst `now ≤ Frist`).
- H6 Done M6a 4: „Schüler-Workspace/Aufgaben-Ordner → 403/400“ auf einen Code festlegen.
- H7 M6e ist groß (Automat, Sperren, Job, Notifier, Suche): Teilung e1 (Zustand/Schreibsperre) / e2 (Job, Benachrichtigungen, Suche) erwägen.
- Bewertung: O1 im Grundsatz richtig (nach Blocker 3), O2 deckt ADR 0008 „eigene Abgaben“, O3 siehe H3, O4 tragfähig (Vereinigung der Zweige). Q1–Q5 technisch tragfähig; Q1: Namenskollision im Wurzelbereich regeln; Q3: `kind=assignments` aus `workspaces.php`/Workspace-Liste ausblenden, Schlüssel für den Editor aber auflösbar lassen.
