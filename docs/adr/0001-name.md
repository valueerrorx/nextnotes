# ADR 0001: Name der App

Status: entschieden (Thomas, 2026-11-02)

## Kontext
Der Auftrag verlangt eine Namensentscheidung per ADR, bevor die App öffentlich benannt wird. MIT regelt keine Namensrechte; „Poznote“ ist der Name des Upstream-Projekts.

## Entscheidung
- Anzeigename: **Next Note**
- App-ID: `nextnote` (Bindestrich ist laut `app-info.xsd` nicht erlaubt: `[a-z]+[a-z0-9_]*[a-z0-9]+`)
- PHP-Namespace: `OCA\NextNote`
- Tabellenpräfix: `nextnote_`

## Konsequenzen
- Herkunft wird in `README`, `info.xml` (Beschreibung) und `UPSTREAM.md` genannt: „Basiert auf Poznote von Timothé Poznanski (MIT)“. `LICENCE` und Copyright-Hinweise bleiben.
- Die App-ID `nextnote` war früher im App Store von brantje/nextnote belegt (eingestellt 2020, heute nicht mehr gelistet). Vor einer Einreichung (M7) prüfen, ob die ID neu vergeben werden kann. Auf Instanzen mit dem alten App-Ordner `apps/nextnote` würde es kollidieren.
